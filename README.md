📊 Adventure Works – Dashboard de Ventas y Logística

Descripción: Este proyecto consistió en el desarrollo de un dashboard interactivo en Power BI para analizar el rendimiento comercial de una empresa a partir de su base de datos interna. El objetivo fue evaluar métricas clave como ventas, ingresos, COGS, gastos totales y desempeño por categoría de producto, tanto a nivel global como específicamente para la sucursal de Estados Unidos, donde se realizó un análisis más profundo por estado/sucursal.
Features:
-Modelado del esquema en Power BI
-KPIs comerciales (ventas, ingresos, márgenes)
-Análisis por región, productos y desempeño de vendedores
-Segmentación por fechas, categorías y canales
-Tecnologías: Power BI, SQL
-Logros: Dashboard completo orientado al análisis de negocio y toma de decisiones.

🧬 Biogenesys – Business Intelligence y Análisis de Procesos

Descripción: Este proyecto consistió en un análisis de datos desarrollado para BIOGENESYS, una empresa farmacéutica interesada en definir su estrategia de expansión en Latinoamérica. El objetivo fue determinar los lugares más adecuados para instalar nuevos laboratorios en Colombia, Argentina, Chile, México, Perú y Brasil, utilizando como base información epidemiológica derivada de la pandemia por COVID-19.
Features:
ETL y limpieza de datos
-Construcción de métricas clave para áreas de operaciones
-Dashboard con indicadores de rendimiento, productividad y tiempos
-Análisis de eficiencia en diferentes procesos
-Tecnologías: Power BI, SQL, Python
-Logros: Visualización profesional para la comprensión del flujo operativo y optimización de procesos.
